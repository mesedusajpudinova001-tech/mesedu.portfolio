# ZÁDU — отдельный сайт кофейни

Подготовлен из актуальной папки `zadu` проекта `mesedu.portfolio`.
Исходная базовая версия: `189edcc560023f304d71170796e3bbda026cfbc3`.
Названия и цены сверены 14 октября 2026 года с уточнённым списком владелицы.
Все страницы, фотографии, названия, цены, описания и КБЖУ сохранены.
Файлы кофейни находятся в корне этого проекта. Ссылки на изображения,
стили и страницы относительные: сайт подходит для отдельного репозитория
GitHub Pages и собственного домена.

## Состояние подготовки

Это готовые исходные файлы, а не уже опубликованный отдельный сайт.
Отдельный GitHub-репозиторий ещё не создан. Старый сайт продолжает работать.

## Публикация отдельно от портфолио

1. Создать публичный репозиторий `zadu-menu` в аккаунте
   `mesedusajpudinova001-tech`.
2. Поместить содержимое этого проекта в корень ветки `main`.
3. Открыть Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Дождаться публикации и проверить главную, все разделы меню,
   девять страниц блюд и оригинальные фотографии.
5. Только после проверки добавить переходы со старых страниц кофейни
   на соответствующие страницы нового сайта. Портфолио не менять.

## Адрес напечатанного QR

https://mesedusajpudinova001-tech.github.io/mesedu.portfolio/zadu/

Нельзя переименовывать или удалять аккаунт, исходный репозиторий
`mesedu.portfolio` или старые адреса кофейни. Они сохраняются как входы
для уже напечатанного QR и старых ссылок.
Подготовка переходов выполняется скриптом `scripts/prepare-legacy-redirects.py`.
Он проверяет все страницы назначения, создаёт отдельный комплект файлов
переходов и сам не меняет опубликованный сайт.

## После покупки домена

1. Купить выбранный владельцем домен у регистратора.
2. Подтвердить владение доменом в настройках аккаунта GitHub Pages
   через выданную GitHub запись TXT.
3. Добавить домен в Settings → Pages → Custom domain нового репозитория
   `zadu-menu`, а затем настроить DNS у регистратора.
4. Для корневого домена добавить записи A GitHub Pages:
   185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153.
   Для `www` добавить CNAME на `mesedusajpudinova001-tech.github.io`.
   В DNS не указывать `/zadu-menu/` и другие пути.
5. Дождаться работы DNS и HTTPS, включить Enforce HTTPS и проверить сайт.
6. Обновить назначения старых переходов на проверенный домен,
   сохранив исходные адреса и распечатанный QR.

Домен кофейни подключается к `zadu-menu`, а не к `mesedu.portfolio`.
Файл CNAME заранее не создаётся: домен ещё не выбран и не куплен.
