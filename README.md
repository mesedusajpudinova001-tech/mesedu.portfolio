## Публикация отдельно

1. Создать публичный репозиторий `zadu-menu` в аккаунте
   `mesedusajpudinova001-tech`.
2. Перенести все файлы этой ветки в корень его ветки `main`.
3. В новом репозитории: Settings → Pages → Deploy from a branch →
   main → /(root) → Save.
4. Проверить сайт, все страницы и изображения.
5. Только после проверки подготовить и опубликовать старые переходы.
   Скрипт `scripts/prepare-legacy-redirects.py` проверяет совпадение
   страниц и сам не меняет опубликованный сайт.

Эта ветка — подготовленные файлы, а не подтверждение отдельной публикации.
Рабочая ветка `main` репозитория `mesedu.portfolio` остаётся прежней.

## Подключение купленного домена

1. Домен покупается у регистратора; конкретное имя ещё нужно выбрать.
2. Подтвердить владение доменом в настройках аккаунта GitHub Pages
   через выданную GitHub запись TXT.
3. В новом репозитории `zadu-menu`: Settings → Pages → Custom domain →
   ввести купленный домен без https:// и путей → Save.
4. Затем настроить DNS у регистратора. Для корня домена добавить
   четыре записи A: 185.199.108.153, 185.199.109.153,
   185.199.110.153, 185.199.111.153.
   Для www — CNAME на mesedusajpudinova001-tech.github.io.
5. Дождаться проверки DNS и выпуска сертификата, включить Enforce HTTPS.
6. Проверить купленный домен и старую QR-ссылку. После проверки можно
   обновить назначения старых переходов на новый домен.

Домен кофейни подключается только к `zadu-menu`.
В `mesedu.portfolio` домен кофейни и CNAME не добавлять.
Отдельный платный хостинг для этого размещения не требуется.

Данные меню: `interior/menu/menu-data.json`.
Генерация HTML: `python scripts/render-menu.py`.
